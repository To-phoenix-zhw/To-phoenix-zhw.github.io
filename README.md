# Hanwen Zhang academic homepage

This repository hosts the personal academic homepage for Hanwen Zhang via GitHub Pages:

https://to-phoenix-zhw.github.io/

## Structure

- `index.html`: homepage content
- `styles.css`: page styling

## Local preview

Open `index.html` directly in a browser, or run a simple static server from the repository root:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/`.
